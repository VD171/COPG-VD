# Code de conduite

Nous voulons que COPG-VD soit un projet accueillant. Soyez respectueux, présumez la bonne
foi, et gardez les discussions techniques et constructives.

- Soyez bienveillant. Pas de harcèlement, d'attaques personnelles ni de discrimination.
- Critiquez les idées et le code, pas les personnes.
- Aidez les nouveaux venus ; tout le monde a été nouveau un jour.

Un comportement inacceptable peut être signalé en privé au mainteneur (voir
[SECURITY.md](SECURITY.md) pour le contact). Les mainteneurs peuvent retirer les
commentaires, commits, issues et contributions qui violent ce code, et peuvent bannir les
récidivistes.

Ceci est une adaptation condensée et adaptée au projet de l'esprit du Contributor Covenant.
