# 행동 강령

우리는 COPG-VD가 환영받는 프로젝트가 되기를 원합니다. 존중하고, 선의를 가정하며, 논의를
기술적이고 건설적으로 유지하세요.

- 친절하세요. 괴롭힘, 인신공격, 차별은 금지입니다.
- 사람이 아니라 아이디어와 코드를 비판하세요.
- 새로 온 사람을 도우세요; 모두가 한때는 새로운 사람이었습니다.

용납할 수 없는 행동은 유지 관리자에게 비공개로 보고할 수 있습니다(연락처는 [SECURITY.md](SECURITY.md)
참조). 유지 관리자는 이 강령을 위반하는 댓글, 커밋, issue, 기여를 제거할 수 있으며, 반복 위반자를
차단할 수 있습니다.

이것은 Contributor Covenant의 정신을 응축하고 프로젝트에 적합하게 적응시킨 것입니다.

*이 문서는 Claude (Anthropic)로 생성되었으며 VD171에 의해 유지 관리됩니다. 수정과 개선을 환영합니다 - [CONTRIBUTING.md](CONTRIBUTING.md)를 참조하세요.*
