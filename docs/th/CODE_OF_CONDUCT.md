# จรรยาบรรณ

เราต้องการให้ COPG-VD เป็นโครงการที่ต้อนรับผู้คน จงเคารพกัน สันนิษฐานว่ามีเจตนาดี และคง
การสนทนาให้เป็นเชิงเทคนิคและสร้างสรรค์

- จงใจดี ไม่คุกคาม ไม่โจมตีส่วนบุคคล หรือเลือกปฏิบัติ
- วิจารณ์ความคิดและโค้ด ไม่ใช่ตัวบุคคล
- ช่วยเหลือผู้มาใหม่ ทุกคนเคยเป็นผู้มาใหม่มาก่อน

พฤติกรรมที่ยอมรับไม่ได้สามารถรายงานเป็นการส่วนตัวต่อผู้ดูแล (ดู [SECURITY.md](SECURITY.md)
สำหรับการติดต่อ) ผู้ดูแลอาจลบคอมเมนต์ commit issue และการร่วมพัฒนาที่
ละเมิดจรรยาบรรณนี้ และอาจแบนผู้กระทำผิดซ้ำ

นี่คือการปรับใช้ที่กระชับและเหมาะสมกับโครงการตามจิตวิญญาณของ Contributor
Covenant
