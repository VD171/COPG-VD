# Kodeks postępowania

Chcemy, aby COPG-VD był przyjaznym projektem. Bądź pełen szacunku, zakładaj dobre intencje i utrzymuj
dyskusje techniczne i konstruktywne.

- Bądź życzliwy. Żadnego nękania, ataków osobistych ani dyskryminacji.
- Krytykuj pomysły i kod, nie ludzi.
- Pomagaj nowicjuszom; każdy kiedyś był nowy.

Niedopuszczalne zachowanie można zgłosić prywatnie do opiekuna (zobacz [SECURITY.md](SECURITY.md)
po kontakt). Opiekunowie mogą usuwać komentarze, commity, zgłoszenia i wkłady, które
naruszają ten kodeks, oraz mogą banować recydywistów.

To skondensowana, odpowiednia dla projektu adaptacja ducha Contributor
Covenant.
