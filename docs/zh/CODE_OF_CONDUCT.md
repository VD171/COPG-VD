# 行为准则

我们希望 COPG-VD 是一个友好的项目。请彼此尊重，默认善意，并让讨论保持技术性和建设性。

- 请友善。不得有骚扰、人身攻击或歧视。
- 批评观点和代码，而不是人。
- 帮助新人；每个人都曾是新人。

不可接受的行为可私下向维护者举报（联系方式参见 [SECURITY.md](SECURITY.md)）。维护者可以删除
违反本准则的评论、提交、问题（issue）和贡献，并可封禁屡次违规者。

这是对 Contributor Covenant 精神的一个精简的、适合本项目的改编。
