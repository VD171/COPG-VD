# Código de conducta

Queremos que COPG-VD sea un proyecto acogedor. Sé respetuoso, presume buena fe, y mantén las
discusiones técnicas y constructivas.

- Sé amable. Sin acoso, ataques personales ni discriminación.
- Critica las ideas y el código, no a las personas.
- Ayuda a los recién llegados; todos fuimos nuevos alguna vez.

El comportamiento inaceptable puede reportarse en privado al maintainer (consulta
[SECURITY.md](SECURITY.md) para el contacto). Los maintainers pueden eliminar comentarios,
commits, incidencias y contribuciones que violen este código, y pueden banear a los
reincidentes.

Esta es una adaptación condensada y apropiada para el proyecto del espíritu del Contributor
Covenant.
