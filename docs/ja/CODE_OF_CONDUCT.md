# 行動規範

私たちは COPG-VD を歓迎的なプロジェクトにしたいと考えています。敬意を持ち、善意を前提とし、
議論を技術的かつ建設的に保ってください。

- 親切に。嫌がらせ、個人攻撃、差別はなしで。
- 人ではなく、アイデアとコードを批判してください。
- 新参者を助けてください; 誰もがかつては新参者でした。

容認できない行為は、保守者に非公開で報告できます(連絡先については [SECURITY.md](SECURITY.md) を
参照)。保守者は、この規範に違反するコメント、コミット、issue、貢献を削除することができ、
繰り返す違反者を禁止することができます。

これは、Contributor Covenant の精神を凝縮し、プロジェクトに適した形に適応させたものです。
