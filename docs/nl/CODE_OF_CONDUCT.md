# Gedragscode

We willen dat COPG-VD een gastvrij project is. Wees respectvol, ga uit van goede bedoelingen, en houd
discussies technisch en constructief.

- Wees vriendelijk. Geen intimidatie, persoonlijke aanvallen of discriminatie.
- Bekritiseer ideeën en code, niet mensen.
- Help nieuwkomers; iedereen was ooit nieuw.

Onaanvaardbaar gedrag kan privé worden gemeld aan de maintainer (zie [SECURITY.md](SECURITY.md)
voor contact). Maintainers mogen opmerkingen, commits, issues en bijdragen verwijderen die
deze code schenden, en mogen herhaalde overtreders verbannen.

Dit is een beknopte, projectgeschikte aanpassing van de geest van de Contributor
Covenant.

*Deze documentatie is gegenereerd met Claude (Anthropic) en wordt onderhouden door VD171. Correcties en verbeteringen zijn welkom - zie [CONTRIBUTING.md](CONTRIBUTING.md).*
