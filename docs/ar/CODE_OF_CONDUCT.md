# مدوّنة السلوك

نريد أن يكون COPG-VD مشروعاً مُرحِّباً. كن محترماً، وافترِض حسن النية، وأبقِ
النقاشات تقنية وبنّاءة.

- كن لطيفاً. لا تحرّش ولا هجمات شخصية ولا تمييز.
- انتقد الأفكار والكود، لا الأشخاص.
- ساعد القادمين الجدد؛ فالجميع كان جديداً ذات يوم.

يمكن الإبلاغ عن السلوك غير المقبول بشكل خاص إلى المشرف (راجع [SECURITY.md](SECURITY.md)
للتواصل). يجوز للمشرفين إزالة التعليقات والـ commits والـ issues والمساهمات التي
تنتهك هذه المدوّنة، ويجوز لهم حظر المخالفين المتكررين.

هذه نسخة مكثّفة ومناسبة للمشروع مقتبسة من روح Contributor
Covenant.

*تم إنشاء هذه الوثائق باستخدام Claude (Anthropic) وتتم صيانتها بواسطة VD171. التصحيحات والتحسينات مرحّب بها - راجع [CONTRIBUTING.md](CONTRIBUTING.md).*
