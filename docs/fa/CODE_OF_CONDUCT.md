# آیین‌نامه رفتار

ما می‌خواهیم COPG-VD یک پروژه پذیرا باشد. محترم باشید، حسن نیت را فرض کنید، و بحث‌ها را فنی
و سازنده نگه دارید.

- مهربان باشید. بدون آزار، حمله شخصی یا تبعیض.
- ایده‌ها و کد را نقد کنید، نه افراد را.
- به تازه‌واردها کمک کنید؛ همه زمانی تازه‌وارد بودند.

رفتار غیرقابل‌قبول را می‌توان به صورت خصوصی به نگهدارنده گزارش داد (برای تماس [SECURITY.md](SECURITY.md)
را ببینید). نگهدارندگان ممکن است کامنت‌ها، commit ها، issue ها و مشارکت‌هایی را که این آیین‌نامه
را نقض می‌کنند حذف کنند، و ممکن است متخلفان مکرر را ban کنند.

این یک اقتباس فشرده و مناسب پروژه از روح Contributor Covenant است.

*این مستندات با Claude (Anthropic) تولید شده و توسط VD171 نگهداری می‌شود. اصلاحات و بهبودها خوش‌آمدند - [CONTRIBUTING.md](CONTRIBUTING.md) را ببینید.*
